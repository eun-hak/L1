# 블로그 카테고리 방향 (NVIDIA Llama 3.1 8B — L2/L3 생성 시 참고)

## 내가 원하는 블로그 스타일
- 검색형 정보글 + 실용 팁 위주
- 네이버·구글에서 실제 검색될 구체적 주제
- L1 범위를 벗어나지 않는 니치한 중분류

## L2 기준
- L1당 15개 내외, 실제 블로그 메뉴/카테고리처럼
- name_ko: 2~12자, 서로 겹치지 않는 하위 주제
- 너무 넓은 이름 금지 (예: "정보", "소식", "전체")
- L1마다 성격에 맞는 하위 축 (예: 이슈/연예 → K-POP, 드라마, 예능…)

## 피하고 싶은 것
- 뻔한 자기계발·명언 카테고리
- L1과 무관한 주제
- 다른 L1과 이름이 겹치는 L2
- "종합", "기타", "전체" 같은 포괄 카테고리
