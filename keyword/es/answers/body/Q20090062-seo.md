# 에어로 코드 사용 방법 | 초보를 위한 완벽한 설정 가이드



```markdown

에어로 코드를 처음 사용하는 초보자도 단계별로 따라가면 쉽게 개발 환경을 설정할 수 있습니다.

## 소개

에어로 코드(Aerocode)는 웹 개발자들이 반응형 웹사이트를 빠르게 구축할 수 있도록 도와주는 개발 도구입니다. 이 가이드는 **에어로 코드**를 처음 접하는 초보자를 대상으로, 설치부터 기본 프로젝트 생성까지 단계별로 안내합니다. 과장 없이 실용적인 방법으로, 복잡한 개념 없이 바로 실습에 집중할 수 있도록 구성했습니다.

---

## 1. 에어로 코드 설치 및 초기 설정

### 1.1 공식 사이트에서 다운로드

1. [에어로 코드 공식 웹사이트](https://aerocode.io)에 접속합니다.
2. 설치 파일은 운영 체제(OS)에 맞는 버전을 선택하여 다운로드합니다. (Windows, macOS, Linux 지원)
3. 다운로드한 파일을 실행하여 설치 마법사에 따라 설치 과정을 진행합니다.

### 1.2 설치 확인

- 설치가 완료되면 터미널(Windows: 명령 프롬프트, macOS/Linux: Terminal)을 열고 다음 명령어를 입력합니다:
  ```bash
  aerocode --version
  ```
- 화면에 버전 번호가 표시되면 설치가 완료된 것입니다. 예: `Aerocode CLI 2.4.1`

### 1.3 환경 변수 설정 (선택 사항)

- 일부 사용자에게는 명령어 실행 시 경로 오류가 발생할 수 있습니다. 이 경우, 설치 경로가 시스템 환경 변수에 추가되어야 합니다.
- Windows: `PATH` 변수에 설치 폴더 경로 추가  
- macOS/Linux: `~/.bash_profile` 또는 `~/.zshrc`에 `export PATH=$PATH:/에어로코드_설치경로` 입력 후 `source` 명령어로 적용

---

## 2. 첫 번째 프로젝트 생성

### 2.1 프로젝트 폴더 생성

1. 터미널에서 다음 명령어로 작업할 폴더를 생성합니다:
   ```bash
   mkdir my-aerocode-project
   cd my-aerocode-project
   ```
2. 해당 폴더 내에서 에어로 코드 프로젝트를 초기화합니다:
   ```bash
   aerocode init
   ```
3. 초기화 과정에서 제공되는 기본 템플릿을 선택하거나, 빈 프로젝트를 생성할 수 있습니다.

### 2.2 개발 서버 실행

- 다음 명령어로 로컬 개발 서버를 실행합니다:
  ```bash
  aerocode serve
  ```
- 브라우저에서 `http://localhost:3000`에 접속하면 기본 템플릿의 예제 페이지를 확인할 수 있습니다.

### 2.3 기본 파일 구조 이해

에어로 코드 프로젝트는 다음과 같은 폴더 구조를 가집니다:
```
my-aerocode-project/
├── assets/         # 이미지, CSS, JS 파일 저장
├── pages/          # HTML 템플릿 파일
├── components/     # 재사용 가능한 UI 요소
├── config.json     # 프로젝트 설정 파일
└── index.html      # 메인 진입점
```

## 💡 FAQ

### Q1. 에어로 코드 사용에 필요한 시스템 사양은?

- **OS**: Windows 10 이상, macOS 10.14 이상, Linux (Ubuntu 20.04 권장)
- **RAM**: 최소 4GB, 추천 8GB
- **Node.js**: v16 이상 (설치 전 확인 필수)

### Q2. 설치 중 "Command not found" 오류가 발생하면 어떻게 하나요?

- 환경 변수 설정이 누락되었을 수 있습니다. 설치 폴더 경로가 시스템 PATH에 추가되었는지 확인하세요.
- Windows 사용자는 명령 프롬프트를 관리자 권한으로 실행한 후 다시 시도해 보세요.
